# 我独自升级 · 学习系统

把「想成为有能力的人」这件事，拆成一场看得见进度的升级。

- 起点：[计算机自学路线图.md](../计算机自学路线图.md)、[数字媒体技术自学路线图.md](../数字媒体技术自学路线图.md)
- 技术栈：原生 HTML / CSS / JS，**零依赖、零构建、可离线**
- 进度保存：浏览器 `localStorage`

## 打开方式

**电脑：双击 `index.html`** 即可（不需要服务器）。

**手机：双击 `serve.ps1`** —— 它会自动起一个本地服务，并打印出手机能访问的地址：

```
电脑打开：  http://localhost:8080
手机打开：  http://192.168.x.x:8080   ← 在手机浏览器里输这个
```

前提：手机和电脑连同一个 Wi-Fi；第一次运行时 Windows 会弹防火墙提示，点「允许」。

> 为什么手机不能直接双击 index.html：iOS 的 Safari 打不开本地文件，安卓多数文件管理器也只能预览不能跑脚本。走局域网最省事。
> 想在外面也能看：把这个 `quest` 文件夹传到 GitHub Pages 或 Vercel（免费），以后任何时候都能访问。

## 四条世界线

| 线 | 定位 | 关数 | 工时 | 节奏 |
|---|---|---|---|---|
| **A 计算机** | 地基。让你能写、能调、能上线 | 6 | 667 h | 主线 |
| **B 数字媒体** | 吃饭的手艺。AIGC 管线 + 图形学副线 | 6 + 2 | 948 h | 主线 |
| **C 素养** | 天花板。英语 / 中国文学 / 法律，**三关并行** | 3 | 300 h | 每天 1 小时，不占主线 |
| **D 创作** | 输出端。B 站 UP 主从定位到运营 | 4 | 300 h | 每周 10 小时 |

> 主线给你饭碗，素养给你判断力，创作给你证据。**三条线权重不同，不是并列。**

## 玩法

| 系统 | 说明 |
|---|---|
| **今日任务** | 地图页顶部直接告诉你「下一件事是什么」；任务全勾完会变成「该验收了」 |
| **关卡** | 学习内容 → 课程与资料 → 任务清单 → 别做 → 奖励 → 考核 |
| **任务** | 每条任务下面标了 **▸ 看什么**（Lil Weng 第几节 / MIT 哪一讲 / 不用看直接动手），避免「一键全看」 |
| **课程与资料** | 共 98 个链接，标了类型（课 / 书 / 文档 / 练 / 工具 / 论文 / B站 / 官方 / 备用）和「看到什么程度停」 |
| **考核** | 每关 3–4 题，答对 **3/4 或 2/3** 合格；不合格可立刻重考，解析指出补哪块 |
| **等级** | E → D → C → B → A → S → 国家权力级 → 超越者（8 级） |
| **每日任务** | 即打卡：基础 10 EXP，连击每级 +2（上限 +20） |
| **里程碑页** | 四条线各自的路线：每关的**累计工时 / 约第几个月 / 能做到什么 / 这时候的你会是什么人**，以及终点画像 |
| **人生进度表** | 四条泳道并行的时间条，横轴是月；点任意一段直达该关 |
| **推荐路线** | 一个开关，把四条线重排成一条 24 个月的主线（先数媒，再补工程），进度表也变成单泳道 |
| **称号获得** | 考核通过、里程碑达成时全屏弹「称号获得」，配火花与扫光 |
| **成就** | 14 个 |

**规则**：等级只是记分牌，作品才是底气。考核不合格就是不合格，没有放水。

## 工时怎么算的

每关的 `hours` 反推自两份路线图自己的承诺：

- 计算机线 667 h ÷ 每周 8–10 h ≈ 15–19 个月（文档写 18 个月）✅
- 数媒线 948 h ÷ 每周 10–12 h ≈ 19–22 个月（文档写 22 个月）✅

里程碑页的「约第 N 个月」= 累计工时 ÷ 该线默认周投入 ÷ 4.33。默认周投入：计算机 9h、数媒 11h、素养 7h（每天 1 小时）、创作 10h。每条线都可以在页面上切换节奏，数字会实时重算。

## 文件结构

```
quest/
├── index.html    页面骨架 + 角色 SVG
├── style.css     全部样式（系统蓝 / 玻璃拟态 / 响应式）
├── data.js       技术线结构：关卡、任务、考题、成就
├── content.js    技术线的学习内容 + 课程链接 + 工时
├── worlds2.js    素养线 + 创作线 + B站资源 + 「看什么」映射 + 系统皮肤
├── milestones.js 里程碑：每关的能力描述、人设、终点画像
├── route.js      推荐路线：把四条并行线重排成 24 个月的主线
└── app.js        逻辑：状态、渲染、考核、每日任务、成就、里程碑
```

三层数据各管一段，互不干扰：

1. `data.js` —— 考什么、几条任务
2. `content.js` —— 技术线学什么、看哪个链接
3. `worlds2.js` —— 新增两条线 + `SEE`（任务→看什么）+ `SKIN`（等级/文案）

## 怎么改

**给任务加「看什么」** → `worlds2.js` 的 `SEE`：

```js
'cs0:0': 'MIT L1 Shell（50 分钟）',   // 关卡id:任务序号 → 看什么
```

**换课程链接** → 对应 stage 的 `resources`：

```js
{ t: '标题', u: 'https://...', k: 'B站', n: '一句话：看到什么程度停' }
```

**加关卡** → `data.js` 的 `stages` 追加（照现有对象抄），再补 `hours / content / resources`。
**加世界线** → `worlds2.js` 的 `EXTRA_WORLDS` 追加一个 world 对象。

**改等级** → `worlds2.js` 的 `SKIN.levels`（名称）和 `SKIN.curve`（累计 EXP 阈值，必须等长）。

**改里程碑描述** → `milestones.js`：

```js
cs3: { cap: '这一关能做到什么', rank: '这时候的你会是什么人' }
```

每条线的 `who`（终点画像）、`note`（这条线给什么）、`pace`（默认周投入）也在这里。

## 深链接

- `?view=sprint` 速通页 · `?view=checkin` 每日任务
- `?stage=e1` 直接打开某一关 · `?exam=u1` 直接进考核
- 关卡面板右上角 🔗 复制当前关卡链接

## 设计上的三个取舍

1. **素养线并行、不进主线。** 英语/文学/法律都是「每天 1 小时、长期复利」的东西，塞进主线会把两年计划拖成四年。
2. **创作线第一关不是「学剪辑」，是「定位」。** 因为 90% 的号死在定位，不是死在剪辑。
3. **每个任务都标「看什么」，并允许写「不用看」。** 自学最大的浪费不是不学，是「把整门课看完」。
